03 · Capabilities

One system. Many modes.

One intelligent layer can support voice, translation, contextual interaction and device integration without changing the underlying communication logic.

MODE 01

Caller ↔ Human

Human communication with an intelligent layer available according to defined rules.

MODE 02

Caller ↔ Li

Li can conduct dialogue, use context and prepare the next communication step.

MODE 03

Caller ↔ Li ↔ Human

Communication can move between AI and a human participant while preserving session logic.

MODE 04

Realtime translation

Multilingual dialogue as a native part of the communication space.

MODE 05

Knowledge & context

Information, contacts, projects and other sources can be introduced according to the scenario.

MODE 06

Device extension

The mobile application can be complemented by home or specialised communication hardware.
